A good model can’t answer from a document it never saw.

When a RAG answer is wrong, walk back up the pipeline:
→ Was the answer in the knowledge base at all?
→ Did retrieval return the right chunk?
→ Was it ranked high enough to make it into the prompt?
→ Only then: did the model ignore what it was given?

Make this cheap to check: log the retrieved chunks next to every answer. Most “model problems” turn out to be search problems.

Save this for the next wrong answer.
